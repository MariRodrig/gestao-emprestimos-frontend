# SysEmpréstimos — Sistema de Gestão de Empréstimos de Equipamentos

Aplicação web desenvolvida para gerenciar equipamentos, colaboradores e empréstimos, com controle de disponibilidade e devoluções.

O frontend foi desenvolvido com HTML, CSS e JavaScript e integrado a uma API REST construída com Java e Spring Boot.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API REST
- Autenticação JWT
- Git e GitHub
- GitHub Pages

## Funcionalidades

- Login com autenticação JWT
- Dashboard com indicadores de equipamentos e empréstimos
- Cadastro, edição e exclusão de equipamentos
- Cadastro e consulta de colaboradores
- Registro de empréstimos
- Controle de disponibilidade dos equipamentos
- Registro de devoluções
- Identificação de empréstimos atrasados
- Interface responsiva

## Backend

O frontend consome uma API REST desenvolvida com Java e Spring Boot, responsável pelas regras de negócio, autenticação e persistência dos dados.## Backend

O frontend consome uma API REST desenvolvida com Java 17 e Spring Boot, responsável pelas regras de negócio, autenticação JWT e persistência dos dados no PostgreSQL.

**Tecnologias do backend:**
- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- JWT
- JUnit e Mockito
- Swagger/OpenAPI
- Render
